# Geogames 🗺️

Коллекция обучающих географических игр. Каждая игра — отдельная папка
в корне репозитория, полностью статическая (HTML + CSS + vanilla JS):
без сборки, зависимостей и сервера — достаточно открыть `index.html`
в браузере.

## Игры

| Папка | Игра | О чём |
|---|---|---|
| [`game_cesko/`](game_cesko/) | Okresy v Česku | районы (okresy) Чехии — 77 штук: интерактивная векторная карта, режим изучения, кликабельный квиз и квиз с вводом названия (диакритика опциональна) |

## Как запустить

Локально — просто открыть `index.html` нужной игры. Для раздачи по HTTP
(например, если игра встраивается в iframe каталога):

```bash
cd game_cesko
python3 -m http.server 8765
# → http://localhost:8765
```

## Устройство игр

Каждая игра самодостаточна и следует общей структуре:

```
game_<страна>/
├── index.html      # страница игры
├── css/            # стили (светлая и тёмная тема)
├── js/             # логика игры + сгенерированные данные карты
├── data/           # исходные геоданные (GeoJSON, WGS84)
├── images/         # справочные картинки
├── scripts/        # генераторы данных карты из GeoJSON
└── README.md       # подробности по конкретной игре
```

Карта в играх — собственная векторная (SVG `<path>` на каждый регион),
генерируется скриптом из GeoJSON: полигоны упрощаются (Ramer–Douglas–Peucker),
проецируются в SVG-координаты, для подписей считаются центроиды.
Благодаря этому каждый регион — отдельный кликабельный элемент,
а подписи не «впечатаны» в картинку и не выдают ответы в квизе.

## Как добавить новую игру

1. Скопировать структуру существующей игры (`game_cesko/`) как шаблон.
2. Положить GeoJSON с границами регионов в `data/`.
3. Адаптировать `scripts/build_data.py` под новый набор данных
   (проекция/масштаб под широту страны) и сгенерировать `js/data.js`:
   ```bash
   python3 -I scripts/build_data.py
   ```
4. Обновить таблицу игр выше.
