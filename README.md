# Geogames 🗺️

Коллекция обучающих географических игр. Каждая игра — отдельная папка
в корне репозитория, полностью статическая (HTML + CSS + vanilla JS):
без сборки, зависимостей и сервера — достаточно открыть `index.html`
в браузере.

## Игры

| Папка | Игра | О чём |
|---|---|---|
| [`game_cesko/`](game_cesko/) | Okresy v Česku | районы (okresy) Чехии — 77 штук: интерактивная векторная карта, режим изучения, кликабельный квиз и квиз с вводом названия (диакритика опциональна) |
| [`cz_geomorphology/`](cz_geomorphology/) | Geomorfologie Česka | геоморфологическое деление Чехии — 4 провинции, 10 soustav и 27 podsoustav (современная терминология: soustava/podsoustava вместо старых subprovincie/oblast из атласа): те же три режима плюс переключатель уровня деления |
| [`cz_nature/`](cz_nature/) | Chráněná území Česka | крупноплошные особо охраняемые территории Чехии — 4 национальных парка и 27 охраняемых ландшафтных областей (CHKO), состояние 2025 г., включая новейший CHKO Soutok: те же три режима; все 31 территория играют вместе (без переключателя категорий), названия всюду несут префикс категории (NP/CHKO) |
| [`cz_water/`](cz_water/) | Vodstvo Česka | реки и водохранилища Чехии — 10 рек (Vltava, Labe, Dyje, Ohře, Morava, Berounka, Sázava, Jihlava, Mže, Odra) и 24 водных площади (каскад Nové Mlýny одним юнитом; 6 водохранилищ, которых нет в атласе, размещены вручную): те же три режима, реки и водохранилища в одном квизе, названия несут префикс категории (řeka/VN). ## Как запустить

Локально — просто открыть `index.html` нужной игры. Для раздачи по HTTP
(например, если игра встраивается в iframe каталога) сервер поднимают из
корня репозитория — тогда играм доступна общая папка `images/`:

```bash
python3 -m http.server 8765
# → http://localhost:8765/game_cesko/
# → http://localhost:8765/cz_geomorphology/
# → http://localhost:8765/cz_nature/
# → http://localhost:8765/cz_water/
```

## Устройство игр

Каждая игра самодостаточна и следует общей структуре:

```
game_<страна>/
├── index.html      # страница игры
├── css/            # стили (светлая и тёмная тема)
├── js/             # логика игры + сгенерированные данные карты
├── data/           # исходные геоданные (GeoJSON WGS84 или векторный SVG)
├── scripts/        # генераторы данных карты из исходных геоданных
└── README.md       # подробности по конкретной игре
```

Справочные картинки игр лежат не в папках игр, а в общей папке `images/`
в корне репозитория (в git не добавляется — см. `.gitignore`); ссылки
в панелях игр указывают на неё через `../images/`.

Карта в играх — собственная векторная (SVG `<path>` на каждый регион),
генерируется скриптом из исходных геоданных: из GeoJSON — с упрощением
полигонов (Ramer–Douglas–Peucker) и проекцией в SVG-координаты,
из готовой векторной карты (SVG) — с сохранением геометрии как есть.
Точки для подписей вычисляются так, чтобы гарантированно попадать внутрь
региона (центроиды или «полюс недоступности»). Благодаря этому каждый
регион — отдельный кликабельный элемент, а подписи не «впечатаны»
в картинку и не выдают ответы в квизе.

## Как добавить новую игру

1. Скопировать структуру существующей игры (`game_cesko/`) как шаблон.
2. Положить GeoJSON с границами регионов в `data/`.
3. Адаптировать `scripts/build_data.py` под новый набор данных
   (проекция/масштаб под широту страны) и сгенерировать `js/data.js`:
   ```bash
   python3 -I scripts/build_data.py
   ```
4. Обновить таблицу игр выше.
